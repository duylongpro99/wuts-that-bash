Prefix match: your most used git commands come first.

Type less, still land on the right command

Prefix matches come first, then the first letters of each word. Letters scattered through the middle of words don't count, so the list stays short.

gi
git push origin master
Prefix. The commands you start most often rise to the top.

gi st
git status
Each chunk you type must start a word in the command.
wib pull,master
git pull origin master
Keyword search. Remember a few words, in any order.

Ranked by how you actually work

Duplicates collapse to one line. What you reach for most is what you see first.

  • Often and recently

    Frequency and recency decide the order. Suggestions come from the last 30 days by default, set with WIB_PERIOD.

  • Your project first

    Among equally good matches, commands you ran inside the current git repository come first. Leave the project and the order goes back to normal.

  • Typos sink

    A command that never succeeded, like gti status, ranks after matches that did. It isn't hidden, and Ctrl-C doesn't count as a failure.

Suggestions that appear on their own

Ctrl-R and fzf make you stop and open a search. wib refines a list with every keystroke, and your keys keep working as before until you press ↓.

Fast enough to run on every keystroke

Each lookup is a short-lived process that reads your history and exits. No index, no daemon, nothing that grows while your terminal stays open.

Install in a minute

Prebuilt binaries from the v0.1.0 release. No Rust toolchain needed.

Requires zsh 5.3 or newer. Your existing ~/.zsh_history works from the first prompt.

    Downloaded with a browser on macOS? Clear the quarantine flag once with xattr -d com.apple.quarantine ~/.local/bin/wib. Each file has a .sha256 checksum next to it in the release.

  2. Hook it into zsh

    Add these to the end of ~/.zshrc, after oh-my-zsh and other plugins.

    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(wib init zsh)"' >> ~/.zshrc

  3. Open a new terminal

    Type gi and your git commands are already there.

Your keys keep their meaning

Keys only change once you press ↓ to select a line. Ctrl-R, completion and history are untouched.

↓
Start selecting, then move down the list
Enter
Run the selected command
Tab
Fill the selected command without running it
Shift Tab
Fill it word by word, to reuse it as a template
Esc
Hide the list until you type again
wib forget
Never suggest a wrong or secret command again
